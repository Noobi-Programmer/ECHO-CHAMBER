# Multi Agent Coordination

Inspect AGENT_SYNC.md and AGENT_STATUS.md. Ask each candidate session to report current runtime/model, tool access, permissions, loaded skills, context/quota constraints and availability. Score task fit and independent reviewer value. Assign temporary roles per task, define exact read/write sets and acceptance criteria, require branch/worktree isolation, and maintain one coordinator lease plus one integration captain per batch. Markdown is not an atomic lock. Record blockers and handoffs.
