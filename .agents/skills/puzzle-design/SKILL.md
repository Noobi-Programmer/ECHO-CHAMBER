# Puzzle Design

Start from the story fact the player must infer. Work backwards to the observable clue and the action that demonstrates understanding. Document exact solution, clue source, alternative interpretations, hint ladder, reset path and softlock prevention. No arbitrary guessing, pixel hunting, colour-only clue, hidden timing requirement or knowledge unavailable to the player. Ask a blind reviewer to solve without coaching.
