# Phaser Engineering

First verify Phaser version and official API docs/examples. Inspect the existing scaffold and task write-set. Keep systems small, typed and data-driven. Use fixed internal resolution and integer scaling for pixel art. Implement explicit scene/state transitions; avoid unnecessary frameworks. Run typecheck/build and a browser test for the changed path. Never invent APIs or add dependencies without approval. This skill is only active if Phaser is approved.
