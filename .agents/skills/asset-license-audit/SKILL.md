# Asset License Audit

Inspect the exact asset or pack page, licence text, creator and source. Separately check platform/API terms. Confirm intended game distribution, modification, commercial use, attribution, share-alike, redistribution and third-party components. Save evidence and a clear APPROVE/HOLD/REJECT decision. A site-level claim or search result snippet is insufficient. Never approve because an asset is labelled free. Escalate ambiguous terms to a human or find an alternative.
