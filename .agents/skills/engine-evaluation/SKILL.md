# Engine Evaluation

Compare candidate engines against the actual game and team constraints. Require a small runnable proof: pixel-perfect room, movement/collision, ECHO past-state toggle, interaction and browser reload/deploy. Record exact version, commands, docs, export issues and implementation time. Use weighted criteria from TECHNICAL_RESEARCH_PLAN.md. Never recommend based only on brand familiarity or broad internet opinion. Do not change engine without human approval.
