# Pixel Art Direction

Define internal resolution, tile size, palette, contrast hierarchy, character scale, UI scale, animation frame budget and visual rules before producing many assets. Use a limited palette; reserve warning accents for meaningful events. ECHO state must be distinguishable by silhouette/texture/labels as well as colour. Avoid blur and fractional scaling. Review assets inside the actual game, not only as standalone images.
