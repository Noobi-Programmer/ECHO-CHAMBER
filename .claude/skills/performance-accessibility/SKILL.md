# Performance Accessibility

Measure rather than guess. Check asset sizes, request count, load time, frame pacing, memory, resize and browser console. Verify keyboard navigation and control discoverability, UI scale, contrast, non-colour clue channels, readable dialogue, audio control and reduced-motion safety. Avoid rapid full-screen flashes. Prioritize blockers and document environment and reproducible steps.
