# Godot Web Engineering

Use only if Godot is approved by engine decision. Verify installed Godot version and official docs. Keep scenes small, node ownership clear and scripts typed where supported. Test an actual browser export early, including loading, input, audio and target hosting. Document Web export constraints and any cross-origin/isolation requirements. Never switch the project to Godot without approval.
