# Browser Game Qa

Play from a fresh load. Test movement, collision, interaction range, ECHO state, puzzles, dialogue, hints, endings, restart, resize, load errors and browser console/network. Report steps, expected vs actual, severity, environment and screenshot. Do not claim to test paths you did not play. Default to read-only; make code changes only under a separate task claim.
