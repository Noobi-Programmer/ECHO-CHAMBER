# Asset Source Policy & Research Notes

This is a starting point for research, not blanket approval for every file on a platform. Confirm current terms and the exact asset's licence before each import.

| Source | Suitable discovery | Required checks |
|---|---|---|
| Pixabay | Images and video through official API/docs where available | API key/terms, current media scope, attribution/standalone redistribution limits, per-item rights |
| Freesound | Sound effects and ambience using API v2 | Individual sound licence, attribution, API terms and commercial status |
| Kenney | Game asset packs; some pages state CC0 | Exact pack page and included notices |
| OpenGameArt | Sprites, tilesets, audio | Exact asset licence; attribution and share-alike obligations |
| itch.io | Indie asset packs | Per-pack licence/readme and author restrictions |
| MyInstants | Inspiration only unless explicit permission exists | Do not scrape or bulk-download; source/licence must explicitly permit game redistribution |

## Policy

- “Free to listen/view” does not mean “free to redistribute in a game”.
- API permission does not replace the asset's own licence.
- Keep proof of licence at the time of acquisition.
- If terms are unclear, contact the creator or find another asset.
- Prefer CC0, public-domain or explicit commercial-use licences for low-friction game assets, while still checking pack contents and third-party notices.
- Do not present copyrighted music, memes or soundboard clips as cleared merely because they are popular online.
